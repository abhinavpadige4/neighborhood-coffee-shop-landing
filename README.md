# Neighborhood Coffee Shop Landing Page

A responsive landing page for a neighborhood coffee shop built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- 🏪 Beautiful hero section with call-to-action
- ☕ Detailed menu with categorized items and prices
- 🖼️ Responsive gallery showcasing the coffee shop ambiance
- 🕒 Clear opening hours display
- 📧 Functional contact form with Formspree integration
- 📱 Fully responsive design for mobile and desktop
- 🎨 Modern UI with coffee-themed color scheme

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Form Backend**: Formspree
- **Deployment**: Vercel

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/abhinavpadige4/neighborhood-coffee-shop-landing.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment Variables

Create a `.env.local` file with your Formspree endpoint:
```
FORMSPREE_ENDPOINT=https://formspree.io/f/your-form-id
```

## Deployment

This project is configured for easy deployment to Vercel:

1. Push to GitHub
2. Import the repository in Vercel
3. Vercel will automatically detect the Next.js configuration and deploy
