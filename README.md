# Neighborhood Coffee Shop Landing Page

A beautiful, responsive landing page for a neighborhood coffee shop built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Modern, clean design
- Fully responsive layout
- Coffee shop themed color scheme
- Interactive components
- Optimized for performance

## Sections

- Hero
- Menu
- Gallery
- Hours
- Contact
- Footer

## Technologies

- Next.js 14
- TypeScript
- Tailwind CSS
- Lucide Icons

## Deployment

This site is deployed on Vercel and automatically updates when changes are pushed to the main branch.

## Local Development

```bash
npm install
npm run dev
```

## Building for Production

```bash
npm run build
npm start
```
